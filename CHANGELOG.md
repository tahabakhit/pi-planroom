# Changelog

## 1.0.0

Initial complete workflow release:

- Explicit investigation mode and conservative runtime planning policy, including nested tool calls.
- Material questions, validated Markdown submission, immutable parent-linked revisions, and private local storage.
- Full-document review/edit/diff/history, revision/workspace/session-bound human approval, and session-only implementation model/thinking selection.
- Current-session implementation or a durable fresh linked session with destination approval.
- Separate progress and reported/observed/human-confirmed acceptance evidence; no inferred completion.
- Branch-aware restoration, compaction recovery, dead-writer inspection, non-overwriting export, and no automatic replay.
- Explicit bounded tool-free independent critique with separate usage records and no approval power.
- TUI/RPC/headless contracts, security/recovery documentation, public-host tests, and packaged CLI qualification.
